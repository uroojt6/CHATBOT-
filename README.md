🤖 AI Chatbot using Python & NLP
🚀 A Smart AI-powered Chatbot that Understands and Responds Naturally!

🔹 Overview
This chatbot is built using Python, Natural Language Processing (NLP), and Machine Learning to engage in intelligent conversations. It can understand user queries, process language contextually, and provide relevant responses.

🛠️ Technologies Used
✔ Python – Core programming language
✔ NLTK & SpaCy – Natural Language Processing (NLP) for text understanding
✔ Scikit-learn – ML models for response generation
✔ streamlit – Backend API for chatbot deployment


📌 Features
✅ Understands & responds to text-based user queries


🧠 How It Works
User Input: The chatbot receives a text message from the user.
Text Preprocessing: NLP techniques clean and tokenize the input.
Intent Recognition: The chatbot classifies the intent using an ML model.
